Prototype, not the built flow

These are the real screens, walkable end to end, with no server behind them. Nothing is stored, nothing is charged, and no email is sent. One code works here so the town rate can be demonstrated: DEMO25 applies the Demo Town Little League rate, and anything else returns the one generic failure message. The town is invented, because naming a real league against a lower price is the thing this design exists to prevent.

In the built site that lookup is server side and rate limited, the rate never appears in the page source, and no list of towns or codes is ever downloadable. Shipping the demo lookup as written would defeat the whole point of the design: anyone could read the page source and see which towns pay less. The rules are in the registration build spec.

Done the right way.
